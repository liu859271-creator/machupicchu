# 馬丘比丘第一視角漫遊

線上遊覽：https://liu859271-creator.github.io/machupicchu/

## 手機怎麼玩

- 左下角搖桿：走路
- 拖曳畫面：環顧四周
- 「地圖」按鈕：開關地圖
- 支援橫向畫面

## 下載

`downloads/machupicchu_dae.zip` 是可匯入 SketchUp 的 COLLADA 模型。在 SketchUp 選擇 **檔案 > 匯入 > COLLADA**，單位為公尺。
